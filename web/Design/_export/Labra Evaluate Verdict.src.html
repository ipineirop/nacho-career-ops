★ Hierarchy of the screen
Header is utility — back-to-Tracker and the save action. Summary header uses typography alone to ground context (no card, no border). The verdict label is the editorial moment: Fraunces ~96px on desktop, ~60px on mobile, with a terminal period that mirrors "The read." from the input screen. Reasoning always sits beneath the label and is sized to put verdict + first 1–2 lines above the fold on a 390 px viewport. Everything else scrolls.
★ Verdict tiers, structurally
Reply (DM, archetype match) — Verdict → Reasoning → Gaps → Comp → Draft reply → Mark-as-replied. Pursue (JD/URL, archetype match) — same shape minus the draft reply, primary CTA opens the posting. Watch (re-surface signal) — pre-saved to Tracker, no comp emphasis, "Why not Pursue today" replaces Gaps, "Re-surface when" lists the unlocking conditions, schema-committed to peer-data / event-based triggers. Skip — short. Verdict + 2-line reasoning + a re-evaluate toggle pointing at Settings → Archetypes. No comp block, no gaps section.
★ Live vs revisited
Same component, same route. The differentiator is a thin band in the header — "Saved · 4 days ago" mono kicker on the left, a dark mono status pill on the right ("In conversation"), and the save button locks to "Saved." The verdict kicker label becomes "VERDICT · ORIGINAL READ" to signal time. Draft reply on a Reply verdict collapses to a one-line confirmation with a "View draft" link — the draft is never gone, just demoted. A new Status section appears between the sent line and Comp, holding the pipeline pills and a free-text "anything I should know" prompt that feeds the moat-relevant outcomes + interactions tables.
★ Comp row · verdict word + state color
One-glance read. The strip leads with a Fraunces verdict word — Fits. / Strong. / Tight. / Below. / Reach. — terminal period, color-keyed to state. Same editorial moment as the main verdict label, smaller scale. State carries through the whole strip via locally-scoped --signal tokens — border-left rule (5px), background tint, track color, dot fill, status glyph. Amber is reserved for actual concern (below floor, undisclosed, stale > 6 months). The mono gloss next to the verdict word gives the headline number (Floor clears by $10k / Quote +$20k over floor). Below the track, the two action lines stay: status (where you are) and next move (what to do).
★ Open & deferred
Reasoning length. 4 sentences feels right on a Reply / Pursue at 17px. Watch and Skip can run shorter. We may want a max-character constraint downstream so Sonnet can't sprawl.
Animation between live and revisited. Not shown in this static frame. The live verdict label reveals after the six-row processing collapses; on revisit, no animation — the page is just there. The frame says "VERDICT · ORIGINAL READ" but doesn't show motion.
Status taxonomy on Report uses the previous session's draft list (evaluated / applied / in_conversation / interviewing / offer / declined / ghosted / passed) — confirm before Tracker session.
Navigation pattern still placeholder. Top-bar nav assumed on desktop, hamburger or tab bar TBD on mobile — owned by the navigation review session.
