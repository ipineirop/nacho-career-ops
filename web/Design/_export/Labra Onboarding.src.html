System notes

One spine, two surfaces. Same tokens, same voice, same step rhythm. Desktop reads at 720px centered — sidebar deferred until post-onboarding. Mobile is thumb-first; identity in the body footer rather than the topbar.

Amber = "I'm not sure". Reused on every low-confidence surface. Warning pill, role-card border, outcome callout, confidence dots — color + verbal label, never color-only.

Reading reveals on the spec stagger (0.2→9.8s). Both surfaces loop so the animation is always visible during review. The amber row on screen 2 sets up the amber row on screen 3. Screen 5 leads with the pattern + a real trade-off, then archetypes, then comp as reference — comp never leads.
